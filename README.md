# :sparkles: BILLETERA VIRTUAL :sparkles:

Este proyecto forma parte del cursado de la materia Analisis y Diseño de Sistemas.

## ¿En qué consiste?

Este proyecto se trata de una billetera vitual con funciones simples y fácil de usar.

- :white_check_mark: Pensada especialmente para personas con poca experiencia en tecnología
- :white_check_mark: Posibilidad de hacer transferencias y pago de servicios
- :white_check_mark: Generación de **subcuentas** para menores con restricciones específicas
